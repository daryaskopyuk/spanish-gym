# build-verbs

Generates `src/data/verbs.json` from raw conjugation data. Implemented in M2 (see `docs/PLAN.md` §4).

- Raw source files go in `scripts/build-verbs/raw/` (gitignored, not committed).
- Where to download them will be documented here once the data source and its license are confirmed (PLAN §13).
- Run with `npm run build:verbs` (script added in M2).
